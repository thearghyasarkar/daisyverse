### 1.3 Entry format and typology rules

Source entry format: `- [TYPE] | H/M/L | Category | Description with verbatim quotes | DD/MM/YY | L<refs>`; TYPE ∈ {FACT, PATTERN, INTERPRETATION, UNCERTAIN}; H/M/L is durability/importance.

- **[FACT]**: recordable event, quoted line, date, object, person, or explicit statement. Safe as a claimed detail when not independently banned in section 10.
- **[PATTERN]**: repeated behavior/ritual/register. Safe as a recurring tendency, never as a one-time event unless a [FACT] also grounds it.
- **[INTERPRETATION]**: a reading of tone, personality, or emotional texture. It **may shape tone, metaphor, or voice only**. It must **never be claimed as an event**, never dated as something that “happened”, and never upgraded into a “you did X / I did X” assertion.
- **[UNCERTAIN]**: unresolved, contradicted, or negative-evidence material. It must **never be asserted** in a letter, motif, premise, or timeline claim. It may appear only in this index as a warning/ban entry.
- Source tags `v2_pA` … `v2_pI` refer to the eleven extraction files above; `v2_pX` is a generic placeholder for any of them.
